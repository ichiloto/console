# Ichiloto Console 0.5.0

Released: 2026-08-21

`0.5.0` brings the Engine 0.5 runtime and Editor 0.5 authoring tools together behind one `ichiloto` command.

The Console can now validate an entire project, run repeatable battle simulations, prepare older projects for versioned saves, open the full-screen Editor, scaffold Engine 0.5 projects, and generate terminal title art. Installing the Console provides the compatible Editor and Engine versions used by those commands.

## Highlights

### Project-wide validation

`ichiloto validate` loads the selected game as the runtime would and evaluates its authored content through the Editor's shared `ProjectValidator`.

The command reports invalid references, identity collisions, map and NPC problems, event and cutscene contracts, summon assignments, achievement targets, battle escape policy, equipment optimization, and save-compatibility metadata without modifying the project.

```bash
cd my-rpg
ichiloto validate
```

### Repeatable battle reports

`ichiloto battle` runs a balancing scenario with the Engine's combat rules and produces a human-readable report of the participants, actions, damage, states, rewards, and outcome.

The report observes the combatants without leaving them mutated after the run, which makes it suitable for repeated comparisons while tuning actors, enemies, skills, and equipment.

```bash
ichiloto battle
```

### Save compatibility upgrades

`ichiloto upgrade` adds the project identity and compatibility metadata required by Engine 0.5's versioned save envelopes.

```bash
ichiloto upgrade
ichiloto validate
```

The generated `assets/Data/save-compatibility.php` file gives later releases an explicit place to describe renamed or removed content instead of guessing how an older save should map onto a changed project.

### Engine 0.5 project scaffolding

New projects declare Engine 0.5 and begin with stable project identity, save metadata, supported player controls, and the runtime structure expected by the Editor and validation commands.

Actor and map generators include safer overwrite handling and richer generated definitions, while the legacy project upgrade path preserves existing project content.

### Editor and title-art commands

`ichiloto edit` opens the Editor 0.5 workspace for the current project. `ichiloto generate:figlet` creates FIGlet title art and terminal wordmarks using the maintained `amasiye/figlet` package.

## Upgrade Notes

Console 0.5 requires PHP 8.4.1 or later and Symfony Console 8. It installs Editor 0.5, which in turn installs Engine 0.5.

Install the complete toolchain:

```bash
composer global require ichiloto/console:^0.5 --with-all-dependencies
```

Update an existing global installation:

```bash
composer global update ichiloto/console --with-all-dependencies
```

Projects created before Engine 0.5 should run `ichiloto upgrade` once and commit the generated compatibility manifest. Run `ichiloto validate` afterward to identify references or identities that need attention before opening an existing save with the new runtime.
